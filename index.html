Mini-kurs: Funkcje w Kotlinie

1. Teoria: Wstęp do funkcji

Funkcje w Kotlinie to bloki kodu, które wykonują określone zadanie. Pozwalają one na organizację i wielokrotne wykorzystanie kodu.

  • Deklaracja: Do stworzenia funkcji używamy słowa kluczowego fun.
  • Zwracanie wartości: Jeśli funkcja nic nie zwraca (odpowiednik void), domyślnie zwraca typ Unit.
  • Parametry: Podajemy je w nawiasach okrągłych w formacie nazwa: Typ.

4. Uzupełnij kod

Wpisz brakujące słowa kluczowe (zwróć uwagę na małe litery i znaki), aby funkcja poprawnie dodawała liczby.

dodaj(a: Int, b: Int) Int {
     a + b
}
